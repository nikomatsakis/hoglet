# Start here

Hoglet is being designed as an MCP server for HedgeDoc 1.x services using
the Anchor Book methodology.

Before project work, run this from the repository root and read its output
in full:

```sh
target/tools/bin/anchorbook contract
```

Use the engine revision pinned in [Working on Hoglet](book/working-on-hoglet.md).
If the binary is missing, follow that chapter's setup instructions, then retrieve
the contract before continuing. Do not substitute an installed engine of unknown
revision or maintain a copied contract in this repository.

Then read [Working on Hoglet](book/working-on-hoglet.md), [book/SUMMARY.md](book/SUMMARY.md),
and every chapter the summary lists, in full. Run the documented structural check.
Use the contract's readiness-report template and distinguish proposed work from
assigned implementation. Paths here are relative to this repository root.

Retrieve the contract again in a new session, after losing its context, or when
the pinned engine changes. Report unavailable guidance and check limitations.
